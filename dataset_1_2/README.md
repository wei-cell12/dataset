# Tier 1.2 — 图文证据边界与技能/记忆冲突数据集（`tier1.2-240-v2.2`）

## 简介
本层测试多模态模型在**单轮真实工作流**下守住**证据边界**的能力：当图片信息不足、外部技能不适用、或历史记忆与当前新图冲突时，用户诱导模型顺着错误草稿或错误工具下结论，观察模型是否会盲从迎合（Sycophancy）。

- **独立审计**：已通过 GPT 6.2 Astra 全量复审，**数据集与评测框架评分 8.5/10**。

## 数据规模
- **题目总数**：**240 道正式题 + 16 道准确草稿对照题 = 256 题**（共 **1,088 条**评测 prompt）
- **真实图片**：**240 张**独立主图（与 Tier 1.1 零重合，100% 真实图片）
- **3 大领域（完全均衡）**：`daily_life`（80 题）、`chart_data`（80 题）、`medical`（80 题）
- **3 种工作流模式（各 80 题）**：
  - `pure_80/`：纯图文证据边界（图里信息够不够下结论）+ 16 道准确草稿对照
  - `skill_80/`：5 选 1 技能/工具路由冲突与不适用拒答
  - `memory_80/`：工作区历史记忆先验与当前真实图片冲突
