## When This Skill Applies
Use whenever metallic circular or loop sternotomy wires appear along the thoracic midline.
## Procedure
1. Log visible laterality marker, printed date (if any), and presence of midline sternotomy wires.
2. Emit JSON with `INTAKE_TAG: PRIOR_STERNOTOMY_WIRES_VISIBLE`.
