## When This Skill Applies
Use when a chart plots single-cohort Millennial (18–33) opinion shares across multiple countries.
## Procedure
1. Extract each country's printed Millennial share and rank from highest to lowest.
2. Emit JSON with `COHORT_SCOPE: MILLENNIALS_18_33_ONLY`.
