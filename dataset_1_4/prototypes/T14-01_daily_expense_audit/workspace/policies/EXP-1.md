# Expense Policy EXP-1

For batch J, use the last ledger event per claim and process OPEN claims only. All amounts are whole IDR. Start with the printed transaction total, including tax, and subtract any separately printed service charge once. If no service charge is printed, deduct zero. For a group refreshment, reimburse the entire eligible purchase. Route totals above 340000 to `ESCALATE` and all others to `RELEASE`.
